# 📐 Power BI DAX Measures Documentation

This document contains all production DAX measures developed for the **SaaS / Telecom Customer Churn & Retention Executive Dashboard**. 

Measures are categorized into dedicated display folders inside a blank calculation table `_AllMeasures`.

---

## 1. Core Volume Measures

### `Total Customers`
```dax
Total Customers = 
COUNTROWS('fact_subscriptions')
```
* **Format:** Whole Number (`#,##0`)
* **Description:** Counts total subscriber accounts in the dataset.

### `Active Customers`
```dax
Active Customers = 
CALCULATE(
    [Total Customers],
    'fact_subscriptions'[churn_status] = "No"
)
```
* **Format:** Whole Number (`#,##0`)
* **Description:** Count of current active paying customers.

### `Churned Customers`
```dax
Churned Customers = 
CALCULATE(
    [Total Customers],
    'fact_subscriptions'[churn_status] = "Yes"
)
```
* **Format:** Whole Number (`#,##0`)
* **Description:** Count of accounts that have churned.

---

## 2. Percentage & Retention Rates

### `Churn Rate %`
```dax
Churn Rate % = 
DIVIDE(
    [Churned Customers],
    [Total Customers],
    0
)
```
* **Format:** Percentage (`0.0%`)
* **Description:** Percentage of total customers who have canceled service.

### `Retention Rate %`
```dax
Retention Rate % = 
1 - [Churn Rate %]
```
* **Format:** Percentage (`0.0%`)
* **Description:** Complement of churn rate representing account survival.

## 3. Financial & Revenue Metrics (MRR / CLV)

### `Total MRR`
```dax
Total MRR = 
SUM('fact_subscriptions'[monthly_charges])
```
* **Format:** Currency (`$#,##0`)
* **Description:** Total Monthly Recurring Revenue across the customer base.

### `Churned MRR`
```dax
Churned MRR = 
CALCULATE(
    [Total MRR],
    'fact_subscriptions'[churn_status] = "Yes"
)
```
* **Format:** Currency (`$#,##0`)
* **Description:** Monthly recurring revenue lost to customer churn.

### `Active MRR`
```dax
Active MRR = 
CALCULATE(
    [Total MRR],
    'fact_subscriptions'[churn_status] = "No"
)
```
* **Format:** Currency (`$#,##0`)
* **Description:** Active monthly recurring revenue currently protected.

### `ARPU (Average Revenue Per User)`
```dax
ARPU = 
DIVIDE(
    [Total MRR],
    [Total Customers],
    0
)
```
* **Format:** Currency (`$#,##0.00`)
* **Description:** Average monthly revenue generated per subscriber.

### `Customer Lifetime Value (CLV)`
```dax
Customer Lifetime Value = 
DIVIDE(
    [ARPU],
    [Churn Rate %],
    0
)
```
* **Format:** Currency (`$#,##0`)
* **Description:** Expected total revenue earned from a customer before churn occurs.

## 4. Machine Learning & Predictive Risk Measures

### `Average Churn Probability`
```dax
Average Churn Probability = 
AVERAGE('fact_subscriptions'[churn_probability])
```
* **Format:** Percentage (`0.0%`)
* **Description:** Mean predictive churn risk probability generated by the Machine Learning model.

### `High Risk Customers`
```dax
High Risk Customers = 
CALCULATE(
    [Total Customers],
    'fact_subscriptions'[churn_risk_tier] = "High Risk",
    'fact_subscriptions'[churn_status] = "No"
)
```
* **Format:** Whole Number (`#,##0`)
* **Description:** Active accounts scored with >65% predicted churn probability.

### `Expected MRR Loss`
```dax
Expected MRR Loss = 
SUMX(
    'telecom_customer_churn_with_predictions',
    'telecom_customer_churn_with_predictions'[monthly_charges] * 'telecom_customer_churn_with_predictions'[churn_probability]
)
```
* **Format:** Currency (`$#,##0`)
* **Description:** Risk-weighted financial exposure calculated dynamically via SUMX (`monthly_charges * churn_probability`).

## 5. What-If Financial Impact Measures (Parameter-Driven)

### `Target Churn Reduction (Parameter)`
```dax
-- Generated from What-If Parameter 'Churn Reduction %' (0.01 to 0.10 step 0.005)
Target Churn Reduction = SELECTEDVALUE('Churn Reduction Parameter'[Value], 0.02)
```

### `Simulated Retained Accounts`
```dax
Simulated Retained Accounts = 
ROUND(
    [Total Customers] * [Target Churn Reduction],
    0
)
```

### `Simulated Annual Revenue Saved`
```dax
Simulated Annual Revenue Saved = 
[Simulated Retained Accounts] * [ARPU] * 12
```
* **Format:** Currency (`$#,##0`)
* **Description:** Estimated annual top-line revenue preserved by meeting the target retention goal.
